# ============================================================
#  Prenoms fictifs utilises dans le depot

#
#  verifier_confidentialite.py compare les noms de `famille.txt` (reel,
#  jamais versionne) a tout ce que git publie. Beaucoup de prenoms sont
#  courants : « Marie » ou « Paul » dans un jeu de test n'identifie
#  personne, mais peut exister aussi dans la vraie famille.
#
#  Ce fichier declare les prenoms volontairement inventes du depot, pour
#  que la verification ne signale QUE les vraies fuites.
#
#  N'ajoute ici qu'un prenom que tu viens toi-meme d'ecrire dans un
#  exemple ou un test. Jamais un prenom reel : ce serait desamorcer
#  l'alarme au lieu d'eteindre l'incendie.
# ============================================================
